# AI_Budget_Buddy 💰
Problem Statement : Students and young professionals often find it difficult to understand their spending and manage budgets.
---
## Solution: 
Build an AI-powered personal finance assistant.
---
## Possible features:
•	Let users enter or import sample transaction data. 
•	Categorize expenses. 
•	Summarize spending patterns using AI. 
•	Answer questions such as, "Where did I spend the most this month?" 
•	Use PayPal Sandbox to demonstrate a relevant payment or checkout flow. 
---
## Technologies:
•	HTML, CSS, JavaScript. 
•	JavaScript with Node.js. 
•	An AI API. 
•	PayPal Sandbox.
